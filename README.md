# Assured Contract Farming System

## Overview
This project is a web-based platform that connects farmers and buyers through secure contract farming.

## Features
- Farmer & Buyer Login
- Product Listing
- Contract Management
- Price Negotiation
- ML Crop Price Prediction
- Notifications
- Payment Tracking

## Tech Stack
### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Spring Boot
- MySQL
- JWT Authentication

### Machine Learning
- Python
- Flask
- Random Forest Regressor
